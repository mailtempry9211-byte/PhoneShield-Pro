# PhoneShield Pro Frontend

Build a complete production-grade frontend for a business application called "PhoneShield Pro".

IMPORTANT:

This project ALREADY HAS a fully working backend API.

DO NOT create any backend code.

DO NOT create mock APIs.

DO NOT use fake JSON data.

Build ONLY the frontend.

The frontend must be built using:

• React 18

• Vite

• Tailwind CSS

• React Router

• Axios

• React Hook Form

• Heroicons

• Framer Motion

• React Hot Toast

• Recharts

• Mobile First Design

The backend API base URL will be:

https://phoneshield-pro.onrender.com/api

Use a centralized API configuration so the base URL can be changed easily later.
